ideia inicial de Configurar

rode o terraform para buildar somente o ecr

salve a URL de output na variavel de ambiente utilizando o export
utilize o export para salvar o AWS_ACCESS_KEY_ID e AWS_SECRET_ACCESS_KEY
rode o comando
    aws ecr get-login-password --region $AWS_DEFAULT_REGION | \
        docker login --username AWS --password-stdin ${REPO_URL%%/*}
rode o comando na pasta raiz
    docker build --platform linux/amd64 -t ${REPO_URL}:${TF_VAR_stage} .
    docker push ${REPO_URL}:${TF_VAR_stage}
salve a URI da imagem do container
    export TF_VAR_lambda_image_uri=${REPO_URL}:${TF_VAR_stage}
rode por fim toda o infra terraform
    terraform apply -auto-approve

coloque as variaveis no .env
rode export $(cat .env | xargs)
